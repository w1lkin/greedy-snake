# 设计文档：微信小游戏-贪吃蛇（网页版为主 + 适配微信）

- 日期：2026-07-27
- 状态：已确认（方案 A：模块化纯静态文件）
- 目标：用 HTML5 + Canvas 实现像素复古风贪吃蛇，键盘/触屏双控，本地保存最近 10 次记录，并生成像素风分享卡用于微信分享。

---

## 1. 目标与范围

### 1.1 目标
- 一个可在浏览器直接打开运行的贪吃蛇游戏（双击 `index.html` 即可，无需构建/服务器）。
- 像素复古（retro pixel）视觉风格，带 CRT 质感。
- 支持电脑（键盘）与手机（触屏滑动）两种操作。
- 用浏览器 `localStorage` 持久化「最近 10 次记录」与「历史最高分」。
- 游戏结束后可一键生成像素风分享卡（PNG），便于在微信中分享。

### 1.2 非目标（YAGNI）
- 不接入真实微信小游戏 SDK（不发布为小程序包）。
- 不做联机 / 排行榜后端 / 账号系统。
- 不引入构建工具、框架或第三方游戏引擎。

---

## 2. 运行平台与适配策略

- **主形态**：HTML5 网页游戏，Canvas 2D 渲染，纯原生 JavaScript。
- **微信适配**：分享产出为一张独立 PNG 卡片（由 `share-card-generator` skill 生成），用户保存/长按即可发到微信会话或朋友圈；游戏本身在浏览器（含微信内置浏览器）中打开运行。
- **本地运行**：所有资源为相对路径，刷新即用；`localStorage` 在 `file://` 同源下可用。

## 4. 游戏核心机制

### 4.1 网格与坐标系
- 逻辑网格：`COLS = 20`，`ROWS = 20`，坐标以格为单位。
- 渲染：每格放大为 `CELL_PX` 像素块（如 16px），整体画布 `400×400`；CSS `image-rendering: pixelated` 保持锐利。

### 4.2 状态机
- `ready`：显示标题、最高分、最近记录、开始按钮。
- `playing`：主循环按 tick 推进蛇。
- `gameover`：显示本局分数、最高分、记录列表、「重新开始」「生成分享卡」按钮。

### 4.3 主循环
- 使用 `requestAnimationFrame` + 累加时间，按固定 `tickInterval`（如 120ms）步进一次；吃食后 `tickInterval` 适度缩短（加速，设下限防过快）。
- 每步：读取方向队列 → 计算新头 → 碰撞检测 → 吃食/移动 → 渲染。

### 4.4 蛇与食物
- 蛇：`array<{x,y}>`，头在前；初始长度 3，居中向右。
- 食物：随机生成于空格，避免与蛇体重叠；吃后长度 +1、分数 +10、tick 加速。
- 碰撞：撞墙（越界）或撞自身即 `gameover`。

### 4.5 分数
- 每吃一个食物 +10 分（常量 `SCORE_PER_FOOD`）。
- 结束写入 `storage`：最近记录追加本条，最高分取 max。

---

## 5. 输入控制

- 统一抽象为「方向队列」（`directionQueue`），仅允许 90° 转向，禁止 180° 反向（避免瞬间自杀）。
- **键盘**：方向键 / WASD 入队；`Space` / `Enter` 在开始页开始、结束页重开。
- **触屏**：监听 `touchstart`/`touchmove`，根据起止位移最大轴判定上/下/左/右入队；用 `preventDefault` 防止页面滚动。
- 输入模块对外只暴露 `enqueueDirection(dir)` 与开始/重开回调，解耦于具体设备。

---

## 6. 本地存储（最近 10 次记录）

- key：`snake_records_v1`，值：`[{ score:Number, date:String(ISO) }, ...]`。
- 写入：游戏结束时 `unshift` 本局记录，截断为最近 10 条（按时间，最新在前）。
- key：`snake_best_v1`，值：`Number`（历史最高分，初始化为 0）。
- 读取时机：`ready` 与 `gameover` 页渲染记录列表与最高分；提供 `getRecords()` / `getBest()` / `addRecord(score)` 接口。
- 健壮性：解析失败 / 隐私模式抛异常时降级为内存空数据，不影响游戏进行。

---

## 7. 分享卡（share-card-generator skill）

- 触发：结束页「生成分享卡」按钮。
- 数据准备（`share.js`）：收集 `{ gameTitle, score, best, date, tip }`。
- 生成：调用 `share-card-generator` 产出一张**像素复古风 PNG 卡**，含：游戏名「贪吃蛇」、本局分数、历史最高分、一句玩法提示（可选二维码占位）。
- 产物：独立图片，展示在页面供长按保存；不阻塞游戏主循环，失败仅提示不影响重开。
- 注：该 skill 在「实现阶段」由编码助手调用，本设计仅约定数据结构与触发点。

---

## 8. 像素复古视觉风格

- 调色板（限定）：背景近黑 `#0b0f0a`、蛇身亮绿 `#39ff14`、蛇头更亮、食物红 `#ff3b3b`、网格线暗绿。
- 渲染：纯色块填充每格，蛇身可加 1px 内描边增强像素感；背景叠加 CSS 扫描线（repeating-linear-gradient）模拟 CRT。
- 字体：CDN 加载像素字体 "Press Start 2P"；离线回退到等宽字体（monospace）。
- 布局：居中卡片式，移动端自适应宽度，canvas 等比缩放。

---

## 9. 错误处理与边界

- `localStorage` 不可用 → 内存降级，游戏照常进行。
- 食物生成死循环防护：空格不足时直接 `gameover`（极少触发）。
- 触屏与键盘重复入队 → 队列长度上限（如 3），超界忽略。
- 页面切后台（`visibilitychange`）→ 暂停循环，回前台恢复，避免「回来已死」。

## 10. 测试与验收

- 手动验收清单：
  1. 双击 `index.html` 可在浏览器运行，像素风正常。
  2. 键盘与触屏滑动均能控制转向且不反向自杀。
  3. 吃食物加分、加速；撞墙/自身结束。
  4. 结束页显示本局分、最高分、最近 10 条记录。
  5. 刷新页面后记录与最高分仍在（localStorage 持久化）。
  6. 「生成分享卡」产出像素风 PNG，可保存。
  7. 移动端（或浏览器移动模拟）布局正常、滑动不滚屏。
